# 📚 StudySnap AI

StudySnap AI is a Gemini-powered educational vision chatbot that helps students understand questions, diagrams, notes, and numerical problems from images.

## 🚀 Features

- 📷 Upload questions, diagrams, and notes
- 🤖 Gemini Vision analysis
- 💬 Follow-up AI conversation
- 🧠 Conversation memory
- 📖 Simple explanation mode
- 🔍 Detailed explanation mode
- 🎓 Exam answer mode
- 🔢 Numerical problem mode
- 📧 Send explanations by email
- 🎨 Streamlit web interface

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini
- Gmail SMTP
